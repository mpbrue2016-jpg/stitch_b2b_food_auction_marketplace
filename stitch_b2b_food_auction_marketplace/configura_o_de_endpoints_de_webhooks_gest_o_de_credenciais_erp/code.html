Políticas de Assinatura Criptográfica & Verificação

RFC 2104 / TLS 1.3

Todos os payloads enviados pela plataforma contêm o cabeçalho X-Varejista-Signature. O timestamp impede ataques de repetição (replay attacks) em até 300 segundos.

HMAC SHA-256 
import hmac, hashlib, time

def verify_varejista_webhook(payload_body, header_signature, secret):
    parts = dict(x.split('=') for x in header_signature.split(','))
    timestamp = parts.get('t')
    signature = parts.get('v1')
    
    if abs(time.time() - int(timestamp)) > 300:
        return False  # Replay attack detectado (> 5 min)
        
    signed_payload = f"{timestamp}.{payload_body}".encode('utf-8')
    computed = hmac.new(secret.encode('utf-8'), signed_payload, hashlib.sha256).hexdigest()
    return hmac.compare_digest(computed, signature)
